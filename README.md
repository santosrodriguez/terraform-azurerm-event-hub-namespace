# terraform-azurerm-cpd-event-hub-namespace

Terraform module that creates an Azure Event Hub namespace with a private endpoint. Public access is optional and limited to IP addresses you specify.

The module code is in the [event-hub-namespace](event-hub-namespace/) folder.

## What it creates

- `azurerm_eventhub_namespace`. The name is generated by azurecaf (`azurerm_eventhub_namespace` naming) from the solution name, location, environment and a random 4-letter suffix.
- `azurerm_private_endpoint` for the `namespace` subresource, registered in a private DNS zone group.

## Network access

| `allowed_ip_addresses` | Result |
|---|---|
| `[]` (default) | Public access disabled. Reachable only through the private endpoint. |
| One or more IPs/CIDRs | Public access enabled with default action `Deny`. Only the listed addresses are allowed, plus the private endpoint. |

Set `trusted_service_access_enabled = true` to let trusted Microsoft services bypass the IP rules.

## Usage

```hcl
module "eventhub_namespace" {
  source = "caresource.pe.jfrog.io/shared-tfmodules-internal__integration/event-hub-namespace/azurerm"
  version = #.#.#

  solution_name       = "claims"
  environment         = "dev"
  location            = "eastus2"
  resource_group_name = "rg-claims-dev-01"

  sku      = "Standard"
  capacity = 2

  private_endpoint_subnet_id = "/subscriptions/<sub-id>/resourceGroups/<rg>/providers/Microsoft.Network/virtualNetworks/<vnet>/subnets/<subnet>"

  # Optional: allow public access from these addresses only
  allowed_ip_addresses = ["203.0.113.10", "198.51.100.0/24"]

  tags = {
    environment = "dev"
    owner       = "cpd"
  }
}
```

## Requirements

| Name | Version |
|---|---|
| azurerm | ~> 4.0 |
| azurecaf (aztfmod/azurecaf) | any |
| random (hashicorp/random) | any |

## Inputs

| Name | Description | Type | Default | Required |
|---|---|---|---|---|
| `solution_name` | Solution name used in the generated namespace name | `string` | n/a | yes |
| `environment` | Environment used in the generated namespace name | `string` | n/a | yes |
| `location` | Azure region | `string` | n/a | yes |
| `resource_group_name` | Resource group name | `string` | n/a | yes |
| `tags` | Tags applied to resources | `map(string)` | n/a | yes |
| `private_endpoint_subnet_id` | Subnet ID for the private endpoint | `string` | n/a | yes |
| `sku` | `Standard` or `Dedicated` (Basic doesn't support private endpoints) | `string` | `"Standard"` | no |
| `capacity` | Throughput units (1-20) | `number` | `2` | no |
| `allowed_ip_addresses` | IPv4 addresses or CIDR ranges allowed over the public endpoint. Empty disables public access. | `list(string)` | `[]` | no |
| `trusted_service_access_enabled` | Let trusted Microsoft services bypass IP rules (only applies when IPs are set) | `bool` | `false` | no |
| `local_authentication_enabled` | Enable SAS/connection-string authentication | `bool` | `false` | no |
| `private_endpoint_dns_zone_ids` | Private DNS zone IDs for the endpoint | `list(string)` | CareSource `privatelink.servicebus.windows.net` zone | no |
| `private_endpoint_dns_zone_group_name` | Private DNS zone group name | `string` | `"default"` | no |

## Outputs

| Name | Description |
|---|---|
| `namespace_id` | ID of the Event Hub namespace |
| `namespace_name` | Name of the Event Hub namespace |
| `primary_connection_string` | Primary connection string (sensitive) |
| `secondary_connection_string` | Secondary connection string (sensitive) |

The connection strings only work when `local_authentication_enabled = true`. By default, use Microsoft Entra ID authentication.
